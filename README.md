# ParcelNest – Parcel Management System

## 📌 About the Project
ParcelNest is a web-based Parcel Management System designed to simplify parcel registration, management, and tracking. It provides a user-friendly interface to manage parcel-related activities efficiently.

## 🚀 Features
- **Parcel Registration:** Register and store parcel details.
- **Parcel Tracking:** Track parcel status and delivery progress.
- **Manage Parcels:** View and manage parcel records.
- **User Interface:** Simple and user-friendly frontend.
- **Backend Integration:** Designed to connect the frontend with backend services for parcel operations.

## ⚙️ Installation and Setup

### 1. Clone the Repository
```bash
git clone https://github.com/srimadhuri1247/ParcelNest.git
```

### 2. Navigate to the Project
```bash
cd ParcelNest/frontend
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Start the Development Server
```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.
